# GitHub Extension

This optional extension contains starter collaboration files for projects that
choose GitHub after the project has a real hosting and review need.

To use it, copy the contents of this directory into the repository root, then:

- Replace and uncomment the placeholder in `CODEOWNERS`.
- Adjust issue labels, assignees, and templates to match the project.
- Keep project-specific workflow assumptions documented in the project docs or
  an ADR when they become durable.

The core template does not require these files.
