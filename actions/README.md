# Actions

Action records convert review findings into follow-up decisions. They should
separate what must be fixed now from what can be deferred with an explicit
reason.

Use action records after reviews, milestone checks, or truth reviews when there
are multiple findings to triage.

Recommended filename format:

```text
YYYY-MM-DD-short-name-action.md
```

See `../examples/actions/example-action.md` for the expected format.
