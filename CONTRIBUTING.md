# Contributing

This repository is an engineering operating template. Contributions should keep
the template lean, stack-agnostic, and useful across many project types.

## Before You Change Files

1. Read `README.md` and `AGENTS.md`.
2. Check the relevant guidance under `guidance/`.
3. Confirm whether the change belongs in the core template or in a future
   project-specific extension.
4. Keep the change scoped and easy to review.

## Contribution Standards

- Do not add sample product code.
- Do not introduce framework, language, package-manager, source-hosting, or
  deployment assumptions.
- Prefer plain Markdown and portable shell.
- Record durable choices in `docs/decisions/`.
- Update examples when changing the formats they demonstrate.

## Pull Requests

Pull requests should explain the intent, summarize key changes, list checks
performed, and note any follow-up work. Reviewers should focus on whether the
template remains clear, minimal, and project-agnostic.
