# Decision Records

Use lightweight architecture decision records for choices that future
contributors should not have to rediscover.

Good ADR candidates include:

- choosing a language, framework, or package manager
- adopting a dependency with meaningful operational impact
- changing a public contract
- accepting a security, reliability, or maintainability tradeoff
- defining a project-specific workflow

Recommended filename format:

```text
YYYY-MM-DD-short-title.md
```

See `../../examples/decisions/example-adr.md` for the expected format.
