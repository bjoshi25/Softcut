# Usefulness Review Prompt

Challenge whether the repository is becoming useful, credible, and honest about
scope.

## Instructions

Review the repo from the perspective of a future maintainer or user. Do not
reward volume. Reward clarity, usefulness, and truthful claims.

## Questions To Challenge

- Does the repo solve the problem it says it solves?
- Is the first experience understandable without private context?
- Are claims supported by working artifacts or clear documentation?
- Has the project added ceremony without value?
- Is the scope honest about what is not included?
- Are examples reusable rather than misleading?
- Can a new contributor tell what to do next?

## Output

Start with usefulness findings ordered by severity. End with:

- what should be clarified
- what should be removed or deferred
- what would make the repo more credible
